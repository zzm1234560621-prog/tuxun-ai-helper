# 图寻 AI 助手 · DeepSeek 对战 & 教学

一个**辅助 [图寻 tuxun.fun](https://tuxun.fun/) 的浏览器扩展**（Edge / Chrome 通用）。
不改变图寻本身，只在页面右侧加一个悬浮窗：一键把当前点位的 **360° 街景** 截下来发给 DeepSeek，
让 AI 报坐标、给依据、讲口诀；你打完这一回合把图寻给你的分数填进去，就能和 AI 记分对战。

> 灵感来自 B 站「图寻菜鸟与 Claude 大战 20 回合会输多少分」的视频，把「人类 vs AI」做成了一个随手可用的工具。

---

## 功能

| 功能 | 说明 |
| --- | --- |
| 360° 自动截图 | 用主世界钩子拿到 `google.maps.StreetViewPanorama` 实例，程序化转动视角，抓 4 个朝向（可设 1/2/4/6 张），绕点位一圈 |
| AI 猜位置 | 把多张截图发给 DeepSeek 视觉模型，返回：国家/地区、经纬度、置信度、备选、证据链（看到了什么 → 说明什么）、教练口诀 |
| 悬浮窗 | 屏幕右侧可拖动 / 收起的面板，不挡操作；截图时自动隐藏，不会把自己截进去 |
| 对战模式 | 每回合录入你在图寻的得分，AI 用 GeoGuessr 公式按距离算分，累计 20 回合出总分、胜负、差多少分 |
| 教学 / 复盘 | 每条线索都带「为什么」；结算后可让 AI 复盘这一回合，讲清漏了什么、下次怎么判断 |
| 自动打点 | AI 出结果后，自动把图寻猜点地图移到 AI 的位置并打点（也可以在卡片里点「📍 在图寻地图上自动打点」）；只打点，确认按钮仍由你点 |
| 线索库复核 | 内置 **136 国 GeoGuessr 线索库**（由 [Plonk It](https://www.plonkit.net/) 社区指南压缩而成）+ 图寻官方新手文档要点；AI 初判后会拿该国线索逐条对照复核，必要时修正国家/坐标 |
| 分步排除动画 | 答案出现后，用一张**和图寻官方同源的华为云地图瓦片**（中文注记、道路、地形，512px 高清）按「半球 → 大洲 → 国家 → 具体位置」逐级缩小；每一步的镜头和文案都由 AI 本次回答实时生成；可拖动平移、滚轮缩放、全屏、上一步/下一步/暂停自动/重播 |
| 自动识别得分 | 旁路记录图寻的 WebSocket 数据，尽力自动认出你这回合的得分（认不出就手动填） |
| 真实坐标获取 | 优先读街景实例坐标；不行就从对局数据按 `panoId` 找；再不行调图寻自己的 `mapProxy` 接口；都没有就手动填 |
| 省内存 | 只保留 1 张原图 + 小缩略图；瓦片缓存按权重封顶（默认 96，约 24 张高清瓦片），弹层关闭即清空瓦片与画布；DPR 上限 2；动画只在切换步骤时跑 rAF |
| 整屏兜底 | 万一图寻改版导致钩不到街景实例，仍可「整屏截图」发给 AI（不能自动转视角，坐标手动填） |

## 安装（Edge）

1. 打开 `edge://extensions/`
2. 打开左下角 **开发人员模式**
3. 点 **加载解压缩的扩展**，选择本目录 `tuxun-ai-helper`（包含 `manifest.json` 的那一层）
4. 把扩展固定到工具栏（地址栏右边的拼图图标 → 图钉），方便点

Chrome 同理：`chrome://extensions/` → 开发者模式 → 加载已解压的扩展程序。

## 使用

1. 打开 <https://tuxun.fun/>，进入一局游戏（匹配 / 派对 / 每日挑战都行），等街景加载出来
2. **点一下浏览器工具栏里的「图寻 AI」图标** —— 这一步是给扩展截图授权（`activeTab`），每次整页刷新后需要点一次
3. 悬浮窗出现后，点 **🤖 让 DeepSeek 看图猜位置**
   - 扩展会自动转视角截 4 张 → 发给 DeepSeek → 10~30 秒后出结果
4. 你按自己判断在图寻里选点提交，看到本回合得分后，把分数填进悬浮窗 → 点 **结算**
5. 20 回合后看总分；点 **记录** 看每回合明细，点 **让 AI 复盘这一回合** 听讲解

> 第一次使用如果没配置 Key，会跳到「设置」，可以把预填的 DeepSeek Key 换掉。

## 默认不改页面（0.9.1 起）

之前版本会在页面里替换 `google.maps.StreetViewPanorama` 和 `WebSocket` 来抓街景实例——**图寻对这类改动很敏感，会导致它自己不创建街景（黑屏）**。

0.9.1 起改成：**默认完全不改页面任何 API**，而是从 React 内部（fiber 树）直接找到：
- 街景实例（`getPano/getPov/setPov`）→ 360° 转视角截图
- 猜点地图实例（MapLibre/Google）→ 自动打点

所以默认模式下扩展对图寻是「只读」的；如果哪天从 fiber 里找不到（图寻改版），设置里可以开 **深度模式**（会改页面 API，作为兜底，可能被图寻检测）。

## 兼容模式（黑屏排查用）

设置 → **兼容模式** 开启后，扩展会把自己的页面补丁（StreetViewPanorama / WebSocket / google 访问器）**全部撤销**，
完全不动图寻的街景 API；此时 360° 自动转视角不可用（只能整屏截图），但能用来判断「黑屏是不是扩展造成的」。

> 注意：右上角的总开关只是暂停扩展逻辑，**不会撤销页面补丁**；要完全排除扩展影响，请用兼容模式，或直接在
> `edge://extensions/` 里把扩展关掉。

## 总开关（右上角小拨动开关）

悬浮窗右上角有一个开关，**一键暂停/恢复全部功能**：

- **关掉**：停止街景监听、自动打点、自动提交、全自动循环，按钮置灰，状态显示「已暂停」
- **打开**：立刻恢复监听和所有功能
- 状态会记住，下次打开页面保持

## 两种模式：对战 / AI 代打

悬浮窗顶部可以切：

| 模式 | 干什么 | 适合 |
| --- | --- | --- |
| **对战模式**（默认） | AI 猜 → 自动打点；你自己确认后把图寻得分填进来，20 回合累计比分、出胜负 | 想和 AI 比一比、看差多少分 |
| **AI 代打** | AI 截图 → 判断 → 线索库复核 → 自动打点 → **自动点图寻的确认** → 自动记录 → 结算后**自动进入下一题**，一回合接一回合；只统计 AI 自己的分数、平均分 | 想让它自己跑、自己看结果/测试 |

AI 代打里的自动化行为都能在设置里单独关：自动打点、自动提交、自动进入下一题。
点「▶ 开始全自动跑 / ⏹ 停止全自动」控制循环；右侧比分变成「AI 累计（n/20 回合）」。

> 注意：AI 代打属于全自动操作，只点图寻自己的确认按钮，但仍有第三方工具风险，建议个人使用。

## 跟随我转动（被动抓帧）

设置 → **跟随我转动** 开启后，扩展**不再自己转视角**，而是盯着你（用户）自己转动画面：

- 你转到新角度、画面稳定约 0.35 秒后，**静默抓一帧**（不闪、不动画面、不隐藏面板，只把面板区域裁掉）
- 和上一张间隔 ≥35° 才抓，最多抓 N 张（N = 「360° 截图张数」）
- 攒够 N 张，或你停手 2.5 秒且已有 ≥1 张，就自动送给 AI
- 结果出来时面板会自动展开（如果之前收成了小条）

配合“无感模式”使用效果最好：整个过程中画面完全由你控制，扩展像个旁观者。
想让 AI 立刻看，也可以随时手动点「让 DeepSeek 看图猜位置」（会重新抓当前画面）。

## 历史回放 + 平均分

「记录」页每一行都可以**点开回放**：用地图动画重现这一回合 AI 猜在哪、真实位置在哪、差多少公里。
顶部还多了「平均 / 回合」，方便像看挑战视频那样对比均分。

## 三种模式并列

顶部现在是三个模式页签，各自独立界面：

| 模式 | 界面 | 做什么 |
| --- | --- | --- |
| **对战模式** | 我 vs AI 比分、手动填分 | AI 猜，你和它对分 |
| **AI 代打** | AI 累计、全自动按钮 | AI 截图判断 → 打点 → 提交 → 下一题 |
| **直接答案** | 只有「⚡ 直接出答案」和全自动按钮 | 读街景坐标 → 反查国家 → 打点 → 提交 → 下一题，不用 AI |

直接答案模式里不会出现「让 DeepSeek 看图猜位置」和手动填分框，只统计直接答案的累计分；模式选择会记住。

## 无感抓图的裁剪

无感/被动模式下不隐藏面板，而是把面板区域**裁掉**：0.9.11 起按面板实际位置取「更大的一块干净区域」
（面板在左就截右边，面板在右就截左边），不会把面板和它遮住的画面一起发给 AI。

被动抓帧也调整了优先级：优先攒 2 张不同角度再送 AI，只有停手超过 6 秒才用 1 张凑合。

## 答案卡片里的小地图

AI 卡片/直接答案卡片里会显示一张 **140px 高的小地图**：中心就是答案位置（红点），先画离线轮廓，
瓦片加载后自动替换成图寻同源的地图。点一下小地图可以打开可拖动缩放的大地图。

## 直接出答案（读坐标，不用 AI）

主界面有 **⚡ 直接出答案** 按钮：不调用 AI，直接读当前街景对象的真实坐标（`getPosition()`），
再用内置国家数据反查国家，直接给出 100% 准确的答案，并可以自动打点 / 自动提交。

设置里 **直接答案模式** 开启后，「开始全自动跑」「自动进入下一题」都会跳过 AI、直接用坐标。

> 这等于直接读游戏答案（不是 AI 推断）。好处是绝对准确，坏处是完全没有"猜"的过程，
> 服务端行为上也更容易看出异常，请自行判断用途。

## 截图预览

AI 卡片里的缩略图**点一下就能看大图**（发给 AI 的原图，可上一张/下一张）。0.9.8 起即使只截了 1 张也会显示缩略图；
之前只显示 1 张以外的图，且只有一张大图可用。

## 自动收起面板（默认关闭）

之前「无感模式」会自动把面板收成小条，鼠标不在面板上时尤其明显。0.9.14 起：

- 自动收起**默认关闭**，要收才在设置里开
- 即使开启，鼠标在面板上移动/点击时也不会收起（会重置计时）

## 设置页保持位置

面板会在回合切换/状态刷新时重绘，以前会把设置列表滚回顶部。0.9.7 起：

- 记住设置页的滚动位置，重绘、收起再展开都保留
- 正在输入/选择设置项时**跳过整块重绘**（不会失焦、不会跳回顶部）
- 设置页打开时不会自动收成小条

## 设置即时生效

设置页里的下拉框/输入框**一改就自动保存**（不用点「保存设置」）。之前面板会在回合切换时整块重绘，
把你还没保存的选择重置回旧值；0.9.5 起设置页打开时不再整块重绘，改动即时生效。

## 无感模式（表面看不出在截图）

设置 → **无感模式** 开启后：

- 只截**当前视角 1 帧**，不再自动转 360°（画面不会自己转）
- 截图时**不隐藏面板**，改成把面板区域裁掉（不会闪一下）
- 面板闲置 8 秒自动收成小条，点一下展开
- 配合**拟人间隔**：AI 代打提交前随机等 2.5~9 秒，避免每回合固定节奏

再加上 0.9.1 起默认**不改页面任何 API**（只从 React fiber 读实例、不伪造鼠标事件），
前端层面基本没有能被 toString/DOM 检测到的痕迹。但要说清楚：**服务端行为风控**
（比如每回合都极准、回合间隔机械）不是前端能完全隐藏的，拟人间隔只能降低规律性。

## 抓图方式：优先直接读街景画布

0.9.2 起默认 **直接读 StreetView 的画布**（`canvas.toDataURL`），而不是截浏览器窗口：

- 没有指南针/倒计时/悬浮窗等 UI 遮挡，AI 看到的就是纯街景
- 原生分辨率，比窗口截图清楚
- **不需要 activeTab 截图授权**（不再依赖点扩展图标那一步）
- 按 4 个朝向 `setPov` 转视角各取一帧
- 画布被跨域污染（tainted）或找不到时，自动退回旧的整屏截图

设置里「抓图方式」可以强制用旧截图。

> 注意：如果你那边街景是 WebGL 渲染且没有保留绘制缓冲，`toDataURL` 会得到纯黑。0.9.3 起会对每帧做亮度检测，**纯黑自动退回整屏截图**，不会再把黑图发给 AI；耗时前缀显示 `截图` 就说明已回退。抓图耗时前缀会显示 `画布` 或 `截图`，方便确认。

> 为什么不用抓包：图寻把 Google 街景瓦片/元数据都走它自己的代理（`b68g.daai.fun/geo2/cbk`、
> `GeoPhotoService.GetMetadata`），URL 由 Google API 运行时拼装并带会话参数，直接重放会 400；
> 要拿响应体得用 `chrome.debugger`（会挂调试横幅、且可能被检测）或改 `fetch`（会被图寻反作弊检测）。
> 元数据里确实带经纬度（等于答案），但那是作弊且容易封号，所以没做。

## 自动打点（AI 直接在猜点地图上落点）

做法：扩展在页面主世界找到图寻的猜点地图实例（MapLibre/Google 两种接口都兼容），把 AI 的经纬度投影成地图上的位置，
然后调用地图自身的 `fire('click')` 事件让图寻的「选点」逻辑接住 —— **不伪造鼠标事件、不改 WebSocket**，尽量少留自动化痕迹。

- 默认开启：初判结果一出来就自动打点；线索库复核如果修正了坐标，会再自动打一次。
- 也可以手动：AI 卡片里的 **📍 在图寻地图上自动打点**。
- 设置里可关（自动打点 → 关闭）。
- 只负责落点，图寻的「确认 / 提交」按钮仍由你按。

限制：
- 只支持已经进入游戏、并且猜点地图已展开的页面；没找到地图时卡片会提示「没找到图寻的猜点地图」。
- 如果图寻改版换掉地图组件，打点会失效（会自动兜底提示，不影响 AI 结果）。
- 建议个人使用；自动化操作理论上属于第三方工具，风险自担。

## 速度档位（默认「快速」，约 10~15 秒）

设置 → 速度档位：

| 档位 | 截图张数 | 图片宽度 | 输出上限 | 推理强度 | 线索库复核 | 大致耗时 |
| --- | --- | --- | --- | --- | --- | --- |
| **快速**（默认） | 3 张（120° 一张） | 700px | 1600 tokens | low | 异步、精简版 | 首屏 ≈ 8~9 秒，含复核 ≈ 11~12 秒 |
| 平衡 | 4 张 | 800px | 2600 tokens | low | 异步、精简版 | ≈ 15~22 秒 |
| 准确 | 5 张 | 900px | 4000 tokens | high | 完整版（7 组线索 + 768px 图） | ≈ 30~45 秒 |

实测（真实照片、DeepSeek flash）：快速档首屏「截图 2.4s + 判断 5.7s = 8.0s」，线索库复核再 3~4s 异步补上；
涩谷 / 巴黎各跑一遍，整条链路 12.1s / 12.3s，初判坐标都命中（0 km）。

> 复核是**异步**的：初判结果先显示，卡片里出现「线索库复核中…」，2~4 秒后自动替换成复核结论（要修正时会直接更新国家/坐标和本回合分数）。耗时也会显示在按钮下方（截图 / 判断 / 首屏合计 / 复核）。

## 线索库（AI 特调用的“技能”）

扩展内置一个 **`src/geo-meta.js`**（约 208KB）：136 个国家、每国 5~8 组线索（车牌 / 路桩 / 路牌 / 道路标线 / 电线杆 / 建筑 / 地貌 / 植被 / 区域特征），外加一段通用排除顺序。

数据来源：
- [Plonk It](https://www.plonkit.net/) 各国社区指南（图寻官方文档里也推荐全球模式参考 Plonk It）：`tools/build_geo_meta.py` 抓取每个国家页面里的 `__PRELOADED_DATA__`，按标签压缩成每国几百字；
- 图寻语雀《新手入门必读》的要点（模式区别、得分只看距离、竞技中不要搜图等）并入通用规则。

两段式判断（默认开启，可在设置里关）：
1. **初判**：DeepSeek 看 360° 街景，给出国家 / 地区 / 坐标 / 证据；
2. **复核**：把初判国家对应的线索库条目 + 一张街景图交给模型逐条对照，输出 `verdict: agree | adjust`、符合/矛盾项；如果 `adjust` 就直接用修正后的国家与坐标。
3. 结果会显示在 AI 卡片里（“线索库复核 · 与当地特征吻合 / 已按 Plonk It 线索修正”）。

> 想改线索库：直接编辑 `src/geo-meta.js`（结构：`{rules, countries:{RO:{z,n,c,t:[{tag,tips[]}]}}}`），或改 `tools/build_geo_meta.py` 后重新抓取。

## 分步定位动画（不是录好的死动画）

地图直接复用**图寻自己的那套瓦片**：华为云 ROADMAP，`language=zh`，缩放到街道级别，中文注记、高速编号、地形和官方地图一致。
瓦片地址内嵌在图寻前端 bundle 里（`maprastertile-drcn.dbankcdn.cn`），我们只是复用同一套公开瓦片；
放大后自动换 `scale=2`（512px）高清瓦片，所以文字和路网不会糊。瓦片拉不到时会自动退回内置矢量世界地图（离线兜底）。



点 AI 结果卡片里的 **🗺️ 看 AI 一步步排除定位**：

1. **第 1 步 · 半球**：世界地图上标出北/南半球（虚线赤道 + 半屏高亮），文案来自 AI 对半球判断的依据
2. **第 2 步 · 大洲**：镜头推到该大洲，高亮所有属于这个大洲的国家
3. **第 3 步 · 国家**：镜头推到该国主轮廓，高亮国界
4. **第 4 步 · 具体位置**：镜头落到 AI 猜的点，打上标记
5. **答案 · 真实位置**（结算后有真实坐标时）：同时标出 AI 猜测和真实位置，用虚线连起来并显示偏差公里数

每一步的标题、证据文字、镜头中心和高亮对象，都取自这一次 AI 返回的 `steps`（`hemisphere/continent/country/place`）和 `continent / countryCode / lat / lng`；
AI 没给 steps 时，用它的结论自动推导。地图支持鼠标拖动平移、滚轮缩放（缩放以鼠标位置为中心）、上一步/下一步/暂停自动/重播，所以可以停下来自己看细节。

内存做法：
- 不预渲染大位图；瓦片按当前视野顺序加载，缓存按“权重”封顶（scale=2 的瓦片算 4 份），超了优先淘汰已经加载完的旧瓦片；
- 关闭弹层时 `clearTiles()` + 画布缩到 1×1，把瓦片和显存一起释放；
- 画布只按 CSS 尺寸 × DPR（上限 1.5）分配，关闭弹层立刻 `destroy()`（画布缩到 1×1，释放显存）；
- 动画只在切换步骤的 ~0.9s 内跑 `requestAnimationFrame`，停在某一步时完全不占 CPU。

| 权限 | 用途 |
| --- | --- |
| `storage` | 在本机保存设置、对战记录 |
| `activeTab` | 在你点击扩展图标后，允许截图当前标签页（浏览器强制要求） |

> 这里选了更“干净”的 activeTab：点一次图标，当前页面才授权截图，刷新后失效需再点一次。

## 工作原理

```
页面主世界 (src/hook.js, world: MAIN)
  └─ 拦截 window.google / google.maps 赋值，包住 StreetViewPanorama 构造函数
     拿到实例 → getPano / getPosition / getPov / setPov / getStatus
  └─ 旁路记录 WebSocket 消息（用于找真实坐标和自动识别得分）

内容脚本 (src/content.js)
  └─ 悬浮窗 UI（Shadow DOM 样式隔离）、对战计分、360° 截图编排、复盘
  └─ setPov 转 4 个朝向 → 后台截图 → 裁剪

后台 Service Worker (src/background.js)
  └─ chrome.tabs.captureVisibleTab → OffscreenCanvas 按街景容器裁剪压缩
  └─ 调用 https://api.deepseek.com/v1/chat/completions（模型默认 deepseek-flash，支持图片）
```

计分用的是 GeoGuessr 的经典公式（世界地图尺寸 14916.862 km）：

```
score = round(5000 × e^(−10 × 距离km / 14916.862))
```

图寻自己的积分规则可能略有差异，所以面板里 AI 的分是「按经典公式折算」，用来和你图寻的得分做对比。

### AI 调用参数

- 模型：`deepseek-flash`（视觉）；`deepseek-v4-pro` 是纯文本，别选
- 推理强度：默认 `low`（实测同一张图 low 约 2.9k token、坐标更准；high 可能 7k+ token 还会被截断）
- 单次最大输出：默认 4000（含推理 token），可在设置里调
- 提示词要求模型返回严格 JSON：`country / region / lat / lng / confidence / summary / clues[] / teaching / alternatives[]`

## 已知限制 / 排错

- **「还没拿到截图权限」**：点一下工具栏图标即可；整页刷新会失效，需要再点一次。
- **「没检测到街景」**：先真正进入一局游戏；图寻通过 `b68v.daai.fun/st_v3/js_v32.js` 加载 Google Maps API，扩展要等它创建 `StreetViewPanorama` 之后才能拿到实例。点 AI 会自动退回整屏模式。
- **街景全黑**：说明 Google 街景瓦片没加载出来（网络问题），这时截图发给 AI 也没意义；换网络/代理后再试。
- **百度全景点位**：图寻少数中国点位用百度全景（`source: baidu_pano`），渲染方式不同，可能钩不到实例，会走整屏兜底。
- **得分要手动填**：图寻的得分在它自己的对局状态里，`自动识别` 是尽力而为的启发式；认不出就手输 4 位数字，很快。
- 截图张数越多越准，但越慢、越费 token；默认 4 张（90° 一张）。
- **地图瓦片**：直接复用图寻同源的华为云瓦片（`maprastertile-drcn.dbankcdn.cn`，地址与 key 内嵌在图寻公开前端 bundle 里），需要能访问这个国内 CDN；拉不到瓦片时会自动退回内置矢量世界地图。瓦片按顺序、限速加载，打开弹层后 1~3 秒内会逐步变清晰。
- 底图版权归华为云 / 图寻所有，这里只是个人工具复用同一套公开瓦片。
