# 图寻答案助手（独立版）

图寻（tuxun.fun）专用的小扩展：**直接显示当前这条街景的真实位置**（也就是这一题的答案），一键在图寻的猜点地图上打点。

- 不需要 AI、不需要 DeepSeek Key、不联网（除了图寻自己的页面）
- 不截图、不需要截图授权
- 只用浏览器标准 API，**Windows / macOS 都能用**（Chrome、Edge）

## 安装（Windows：Edge / Chrome）

1. 打开 `edge://extensions/`（Chrome 是 `chrome://extensions/`）
2. 打开左下角的 **开发人员模式 / Developer mode**
3. 点 **加载解压缩的扩展 / Load unpacked**
4. 选择 `tuxun-answer` 这个文件夹（能看到 `manifest.json` 的那一层）
5. 加载后在工具栏固定「图寻答案助手」

## 安装（macOS：Chrome / Edge）

完全一样，因为这是浏览器扩展，不是 Windows 程序：

1. 把 `tuxun-answer` 文件夹拷到 Mac 上
2. 打开 Chrome/Edge，地址栏输入 `chrome://extensions` 或 `edge://extensions`
3. 打开 **开发者模式**
4. 点 **加载已解压的扩展程序**
5. 选择 `tuxun-answer` 文件夹

> 不支持 Safari 和 Firefox。

## 使用

1. 打开 https://tuxun.fun/ 并进入一局游戏
2. 右上角会出现「图寻答案」小面板
3. 面板会直接显示：**国家 + 经纬度**，以及一张可交互的小地图（滚轮缩放、拖动平移、双击放大；点一下打开大图）
4. 点 **📍 打点** 会在图寻的猜点地图上落点；也可以开「自动打点」（每道新题自动落点）
5. **复制** 复制国家+坐标，**地图链接** 打开 Google 地图看位置

面板可拖动（拖标题栏），`−` 收起成小条。

## 线索库（判断技巧）

覆盖世界地图数据里的**全部 175 个国家**（另含港澳台、关岛、格陵兰、极地/岛屿领地、跨国溢出等扩展地区，共 208 条），全部为中文精简线索；
线索库默认折叠、可展开，过长时框内滚动。


面板会按当前国家自动显示 **Plonk It 线索库** 里这个国家的判断技巧（按车牌/路桩/电线杆/建筑/植被/语言/区域分类），
点击标题可展开/收起，内容过多时内部滚动。数据来自 `src/geo-meta.js`（与完整版共用）。

## 中国模式显示省份

在中国地图模式里，面板除了国家还会反查**具体省份**（内置简化省界，离线判断），
例如显示「中国 · 辽宁省」。数据来自阿里云 DataV 行政区划边界，脚本在 `tools/build_cn_provinces.py`。

## 打点原理（两条路）

1. 找到图寻猜点地图对象 → 调它自己的 `fire('click')` 选点
2. 找不到地图对象时，直接从图寻 React 组件的 props 里找 `setPickCoord` / `onPickLocation` 等回调，替它选点

失败会自动重试 3 次（地图可能比街景晚加载）。面板上的 **诊断** 按钮会显示两条路各自的探测结果，排查时截图发回来即可。

## 和完整版的区别

| 功能 | 独立答案版 | 完整版 |
| --- | --- | --- |
| 直接出答案 | ✅ | ✅ |
| 自动打点 | ✅ | ✅ |
| AI 猜位置 | ❌ | ✅ |
| 对战计分 / 历史 / 地图动画 | ❌ | ✅ |
| 需要 API Key / 联网 AI | ❌ | ✅ |

## 注意事项

- 这是**直接读游戏答案**（读取街景对象自带的经纬度），属于作弊性质，可能违反图寻规则，风险自担。
- 如果点「打点」提示「没找到图寻的猜点地图」，确认已经进入游戏、并且右下角猜点地图已展开。
- 扩展不会向任何第三方服务器发送数据。
